## Agent skills

### Issue tracker

Issues and PRDs live as GitHub issues in `shancept/quiz-updater`, managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context layout — `CONTEXT.md` + `docs/adr/` at the repo root (created lazily by `/domain-modeling`). See `docs/agents/domain.md`.

## Установка приложения на другой Mac

Если пользователь просит установить QuizUpdater на этот Mac (в том числе Intel) — действуй строго по `docs/INSTALL.md`, шаг за шагом, и в конце отчитайся по его чек-листу. Ключ сервисного аккаунта — секрет: не читай и не печатай его содержимое, не коммить и не загружай; презентации Keynote не меняй (для проверок только `--dry-run`).
